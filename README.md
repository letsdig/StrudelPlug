# StrudelPlug

**StrudelPlug** is a native Linux VST3 audio plugin that embeds the live-coding environment **[Strudel](https://strudel.cc/)** directly into your DAW, streaming real-time multi-channel Web Audio and MIDI straight through the track channel strip.

Designed for live coders and electronic music producers, StrudelPlug eliminates external PipeWire/JACK patchbays and bridges TidalCycles-style algorithmic patterns directly into your DAW mixing chain.

---

## Tested & Verified With

- **Bitwig Studio 5+ (Linux)**: Tested extensively. Full bidirectional audio, transport sync, and MIDI routing.
- **DAW Support**: Any VST3-compatible Linux host (Bitwig, Reaper, Ardour).

---

## System Compatibility: Ubuntu 24.04+ ONLY

> ⚠️ **IMPORTANT COMPATIBILITY NOTICE**:  
> **StrudelPlug is built specifically for Ubuntu 24.04 LTS (Noble Numbat) and newer.**  
> **Ubuntu 22.04 and older distributions are strictly UNSUPPORTED.**

### Why Ubuntu 24.04+?
- Requires modern **WebKitGTK 4.1+** with in-process low-latency Web Audio routing and IPC event emitters.
- Built against **GCC 13+** with **C++20** standard library and **glibc 2.38+**.
- Requires modern PipeWire / ALSA driver stacks for sub-10ms buffer scheduling.

## Features

- **Direct In-Track Audio Routing**: Audio synthesized by Strudel / Superdough is captured in-memory and injected directly into the DAW track buffer (`processBlock`). No external patchbays or JACK routing required.
- **Bidirectional MIDI**: Send MIDI notes and CC from your DAW tracks and controller keyboards directly into Strudel, and capture MIDI patterns generated by Strudel back into your DAW (`.midi()` streams directly into DAW instruments or via Bitwig's Note Receiver).
- **DAW Transport Sync (`● SYNC DAW`)**:
  - When enabled, pressing **Play** in Bitwig triggers Strudel pattern evaluation.
  - Pressing **Stop** in Bitwig silences output instantly (0 ms) and stops the Strudel scheduler.
  - Toggle off for free-running live coding independent of DAW transport.
- **Full DAW Project State Persistence (v1.0.9+)**: Live code typed into Strudel, SYNC DAW toggle, sample rate, cushion size, and gain trim are automatically saved into your DAW project file and seamlessly restored upon opening.
- **Ultra-Low CPU Architecture (v1.0.9+)**: 512-sample frame batching cuts WebKit IPC overhead by 75%, while an intelligent 500ms silence hangover drops CPU usage to **~0%** when DAW transport is stopped.
- **Local Strudel**: The REPL is served from the plugin's own bridge server over plain `http`, so the page can open the MIDI-in WebSocket that an `https` page refuses. The `↓` button in the settings row (`⚙`, top right) downloads the latest `@strudel/repl` package from the npm registry into the user's app-data directory (`StrudelPlug/strudel`); press it again any time to update. Works offline afterwards (synth sounds only; samples still need internet). Until a build is installed the page shows a warning instead of a blank editor. Strudel is AGPL and is not bundled with the plugin.
- **Extended Buffer Options (up to 16384 samples)**:
  - Selectable buffer cushion: `128`, `256`, `512`, `720` (15ms), `1024`, `2048`, `4096`, `8192`, `12000`, and `16384` samples (~340ms).
  - Real-time digital LCD telemetry display showing sample rate, transport state, output dB level, and buffer status.
- **Transient De-Clicking**: Soft micro-fade on startup and buffer flushes eliminates DC offset clicks and digital pops.
- **OpenSynth1 Aesthetic**: Sleek dark titanium hardware finish with cyan digital LCD readouts, dedicated options strip with real-time audio volume and MIDI activity LEDs, and output gain trim slider (-24 dB to +6 dB).

## MIDI Output in Bitwig Studio & DAWs

Strudel patterns can stream MIDI notes directly into your DAW track channel strip by appending `.midi()`:

```javascript
// Output MIDI notes on default channel:
$: note("c3 eb3 g3 bb3").midi()

// Target a specific channel (1-16):
$: note("c3 eb3 g3 bb3").midichan(1).midi()

// Chord progressions:
$: chord("<Cm7 Fm7 Gm7 Cm7>").voicing().midi()
```

The real-time **MIDI** indicator LED in StrudelPlug flashes green on every note event.

### Routing in Bitwig Studio:
- **Same Track (Serial Chain)**: Place any software synth (e.g. Polymer, Polysynth, or any VST) immediately after `StrudelPlug` in the track device chain.
- **Separate Track**: On any other track, add Bitwig's native **Note Receiver** device before your instrument and select `Source: Track 1 -> StrudelPlug`.

## Building from Source (Ubuntu 24.04+)

### 1. Install Dependencies
```bash
sudo apt-get update
sudo apt-get install -y \
    build-essential \
    libwebkit2gtk-4.1-dev \
    libgtk-3-dev \
    libasound2-dev \
    libjack-jackd2-dev \
    libfreetype-dev \
    libx11-dev \
    libxcomposite-dev \
    libxcursor-dev \
    libxinerama-dev \
    libxrandr-dev \
    libgl1-mesa-dev
```

### 2. Compile Release Build
```bash
make -C Builds/LinuxMakefile CONFIG=Release -j$(nproc)
```

### 3. Install to System VST3 Directory
```bash
mkdir -p ~/.vst3
cp -r Builds/LinuxMakefile/build/StrudelPlug.vst3 ~/.vst3/
```

Then open or rescan your plugins in Bitwig Studio:
`StrudelPlug` will appear under your VST3 instruments / effects.
